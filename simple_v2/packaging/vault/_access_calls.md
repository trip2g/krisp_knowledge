Всё, что пайплайн созвонов пишет, лежит в круге `calls`, то есть видно только
владельцу.

Круг назначается папкой, а не памятью автора, потому что заметка без круга
читается любым, у кого есть ключ к базе. Пустой список субграфов это не
«приватно по умолчанию», это «видно всем ключам», и цена ошибки здесь не
неточная заметка, а чужой человек, читающий чужой разговор.

```jsonnet
{ subgraphs: ["calls"] }
```
