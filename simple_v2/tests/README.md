# tests — офлайновая проверка скриптов calls

```
cd simple_v2
python3 tests/run.py
```

Одна строка на случай, первый упавший печатает трейс и выходит с кодом 1.
Стандартная библиотека, ничего ставить не нужно. Порядок зависимостей —
только `tests/ -> packaging/`; ничего из `packaging/` сюда не смотрит.

## Что покрыто

**intake.py — нормализация.** Три формы пересланного файла, по фикстуре на
каждую: `Speaker N | MM:SS` с текстом на следующей строке, `Имя: реплика` без
таймкодов, и голая проза без того и другого. Проверяется, что заголовок и
слова склеиваются в одну нумерованную строку, что `labels` и `timecodes` во
фронтматтере совпадают с тем, что в файле правда было, и что нумерация
стабильна: два прогона дают побайтово одинаковое тело.

**Двухпроходный детектор меток.** Фикстура `shape_d_colon_trap.txt` содержит
строку «Вопрос: кто это делает?». Метка признаётся, только если открывает две
строки и больше, поэтому «Вопрос» спикером не становится, а двоеточие внутри
реплики («Тогда так: сначала макеты») остаётся в словах.

**Дубли по sha256.** Тот же файл второй раз — отказ с именем существующей
заметки и никакой второй заметки в базе; тот же файл под другой датой — тот же
отказ, потому что id это хеш тела, а не даты. Без `--date` — отказ, а не
сегодняшнее число.

**Демо из архива.** `packaging/demo/call.txt` прогоняется через `intake.py` с
заголовком и датой из самой засеянной заметки, и результат сравнивается с
`packaging/vault/transcripts/*.md` побайтово. Если кто-то поправит демо-txt или
заметку по отдельности, тест падает — то, что лежит в архиве, обязано быть
ровно тем, что выдаёт инструмент. Заметка ищется по id8, посчитанному из
демо-файла, поэтому переименование и смена заголовка тесту не мешают.

**Ворота 1.** Текст вопроса (дата, заголовок, метки, первые строки), отказ на
метку, которой в транскрипте нет, со списком настоящих меток; запись
`review/go` со ссылкой на транскрипт; карточки в `people/unconfirmed/` со
ссылкой на созвон; отказ на второй ответ по тому же созвону; «семейный» и «не
разбирать» → `review/done`.

**Резак (ворота 2).** Нарезка по номерам строк, якорь вида «строки 1–5»,
подстановка имён владельца вместо меток. Граница вне диапазона притягивается к
ближайшей реальной строке и снап пишется в `boundary_snaps`; дубль границы
выбрасывается и тоже записывается; граница дальше 25 строк от диапазона —
жёсткий отказ, черновик не пишется. Префикс `L` терпится. Файл без меток
цитируется без строки атрибуции — имя не выдумывается.

**Дословность.** По всем пяти файлам (четыре фикстуры + демо) каждая цитата в
черновике проверяется как подстрока исходного txt. Строки атрибуции
(«Иван Петров | 00:00») из проверки исключаются явно, по списку, собранному из
транскрипта, а не по форме строки.

**Ворота 2 — приёмка.** Правки владельца ложатся датированной секцией под
черновиком, сам черновик не меняется; `## Вынести` пишется всегда, в том числе
пустой; повторный `accept` отказывает.

**Крон и остальное.** `ask` берёт сначала ворота 2, отмечает вопрос в
`state/calls.md` и на том же тике молчит; отвеченный созвон уходит из очереди;
созвон 2019 года всё равно спрашивается (умолчание `since` — не сегодня);
`person` переносит карточку и сохраняет ссылку на созвон; `retrigger` трогает
только фронтматтер; `status` ничего не пишет; `init` ставит границу архива.

**Контракт с остальным пакетом.** Рецепт sha256 воспроизводится из заметки на
диске; `source` ни на что не влияет (заметка с `source: demo` работает);
`circle`, `subgraph` и `call_id` в скриптах отсутствуют, подкоманды `circles`
нет.

## Чего здесь нет — и почему

- **Живого волта.** `tests/vault_stub.py` подменяет пять функций доступа, а
  `gql` заставляет падать: тест, дотянувшийся до сети, обязан упасть, а не
  висеть на сокете. Значит не проверены сам GraphQL, форма ответа платформы и
  права доступа. Первый прогон на настоящей базе — отдельный ручной шаг.
- **Гонки за хеш.** Заглушка пишет, не сверяя `expectedHash`, поэтому ветка
  «заметка изменилась под нами» (`REFUSED: vault … changed under us`) не
  покрыта.
- **Роли segment.** Карта границ в тестах пишется руками в том формате, который
  роль обязана выдавать. Что модель действительно его выдаёт — не здесь.
- **Телеграма и агента.** Пересылку файла, распознавание речи и разговор с
  владельцем никто отсюда не трогает.
- **Крона по времени.** Напоминание через 24 часа не проверяется: тест не
  двигает часы.
